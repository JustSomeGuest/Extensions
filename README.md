# Extensions

Browser extensions made by me.

## Setup

First, open the folder for the browser you want to use:

- **[Firefox Extensions](ManifestV2)** - Extensions for Firefox and Firefox-based browsers.
- **[Chrome Extensions](ManifestV3)** - Extensions for Chrome and Chromium-based browsers.

Open the folder of the extension you want, download its extension file, then follow the instructions below.

## Manifest V2

Firefox extensions use `.xpi` files.

1. Go to `about:addons`.
2. Click the **Settings** icon below the search bar.
3. Select **Install Add-on From File...**
4. Select the downloaded `.xpi` file.

Done!

## Manifest V3

Chrome extensions use `.crx` files.

1. Go to `chrome://extensions`.
2. Enable **Developer mode**.
3. Drag and drop the downloaded `.crx` file onto the page.
4. Confirm the installation if prompted.

Done!

## Chrome Extensions on Mobile

Want to use Chrome extensions on Android? Try [Quetta Browser](https://play.google.com/store/apps/details?id=net.quetta.browser), which supports Chrome extensions on mobile.
