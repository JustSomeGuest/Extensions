# NexTab

NexTab replaces the new tab page with a calm, minimal start page that's yours to shape.

Make it yours
- Wallpapers: gradients, solid colors, image URLs, or uploads (stored locally, auto-downscaled)
- Widgets: clock (12/24h, seconds), date, greeting, weather, focus/todo, quotes: toggle each one
- Search bar with 6 engines (Google, Bing, DuckDuckGo, Brave, YouTube, GitHub) and URL detection
- Shortcuts: add, edit, delete, drag to reorder, local HD icons
- Layouts: top, centered, compact; dim + blur controls

Tab reuse, built in
- One reusable New Tab per window, one tab per watched website with subdomain matching
- Toolbar popup with quick toggles, Ctrl+Shift+N to jump to your New Tab
- Website rules, duplicate cleanup, all in the Tabs settings pane

Private by design
- Everything lives in local extension storage: no accounts, no analytics
- Weather uses keyless Open-Meteo; location mode stores only coarse ~1km coords labeled "Current location", never reverse-geocoded

Free, offline-first, and keyboard friendly (/ to search, S for settings).
